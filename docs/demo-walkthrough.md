# 演示动线与录屏脚本（S29.1 后）

> 用途：面试现场演示 / 录一段 3 分钟视频贴简历。目标不是"功能罗列"，而是**让人 3 分钟内看懂这是什么水平的系统**。
> 环境：`https://sdblog.qdappt.us.ci`（前台）、`https://admin-sdblog.qdappt.us.ci`（后台）。

## 2. 开播前 60 秒自检（必做）

```bash
cd ~/sdblog/current
./deploy.sh status | head -5          # 7 服务 healthy、版本与 digest
./smoke-public.sh                     # 8/8 才算可录
```

- 电脑**不要休眠**（WSL 睡着隧道就断，页面会 502）
- 浏览器开两个标签：前台 + 后台，都先登录好，录制时不用输验证码
- 浏览器缩放 100%，窗口 1440 宽（截图/录屏板式最好看）

## 3. 三分钟六站（每站 20~30 秒，一句话台词）

| # | 动作 | 台词要点（讲"为什么"而不是"有什么"） |
|---|---|---|
| 1 | 首页（`/`） | "多作者技术博客，SSR 首屏直出；编号 01/02/03 是编辑式版式，不是卡片瀑布。" |
| 2 | 搜索 `Docker`（`/search`） | "ES + IK 分词，服务端高亮 `<em>`；ES 故障自动降级 MySQL LIKE，接口契约不变。" |
| 3 | 点进任意文章 | "详情一次请求带出上一篇/下一篇；正文 HTML 是后端 jsoup 白名单净化过的；代码块是保存时用 shiki 高亮。" |
| 4 | 作者中心（`/me`）→ 新建草稿 → 发布 | "所有注册用户天然可发文，走 `/blog/article/**` 作者自助层；归属由后端按 author_id 强制校验，不信任前端。" |
| 5 | 后台治理（`admin` → 文章治理）→ 下线一篇 → 恢复 | "下线只改 visibility=2，不动 status；作者隐藏与管理员下线是两个独立状态；治理只在后台，前台拿不到 `/blog/admin/**`。" |
| 6 | 终端跑 `./deploy.sh status` + 一次 `rollback` | "四枚私有镜像按 digest 发布，回滚 55 秒；同机还并存着另外三套 compose 栈，端口/卷/项目名全隔离。" |

> 第 6 站是加分项：多数候选人只能演示页面，你能演示**发布与回滚**。

## 4. 录屏建议

- Windows 用 `Win + G`（Xbox Game Bar）或 OBS，1080p / 30fps，录完导 MP4
- **不要录**输密码、验证码刷新、终端里大段 JSON 日志
- 结尾加一张静态卡片（可截图 `deploy.sh status`），写三个数字：**2m18s 发布 / 55s 回滚 / 75 个后端单测**
- 视频控制在 2~3 分钟；简历里写"演示视频（3 分钟）+ 在线 Demo（按需开启）"

## 5. 已知翻车点

| 现象 | 原因 | 避免方式 |
|---|---|---|
| 打开 502 / 白屏 | WSL 休眠或隧道断开 | 录前跑 `smoke-public.sh`；Windows 电源计划设"从不睡眠" |
| 图片不显示 | 图片域走 MinIO，桶策略或隧道异常 | 打开任意带封面文章确认图片出得来 |
| 首屏偶发空白 | 刚重启后 Cloudflare 边缘预热（实测 1~2 分钟） | 录前预热一次首页 |
| 后台登录慢 | 验证码 + RSA 加密链路（正常） | 提前登录好两个标签页 |
